# Représentation

> [!abstract] Définition
> Pouvoir d'accomplir un acte juridique au nom et pour le compte d'autrui, dont les effets se produisent directement sur la tête du représenté ([[Art. 1153]] à [[Art. 1161]]).

## À retenir
- Parfaite ou imparfaite (commission) ([[Art. 1154]]) ; sources légale, judiciaire, conventionnelle ([[Art. 1159]]).
- Pouvoir général : actes conservatoires et d'administration ; pouvoir spécial : actes visés ([[Art. 1155]]).
- [[Action interrogatoire]] du tiers ([[Art. 1158]]).
- Actes avec soi-même interdits pour les personnes physiques ([[Art. 1161]]) ; affaire Adidas-Tapie.
- Dépassement de pouvoir : inopposabilité, sauf [[Mandat apparent]] ([[Art. 1156]]) ; détournement : nullité ([[Art. 1157]]) ; ratification possible.
- Le dirigeant n'est responsable envers les tiers qu'en cas de faute séparable de ses fonctions ([[Com., 20 mai 2003 (Seusse)]]).
