# Minimal edits
1. Confirm requested behavior and acceptance criteria.
2. Find the narrowest implementation point and inspect nearby conventions.
3. Avoid unrelated cleanup, formatting and dependency upgrades.
4. Edit only required lines/files; preserve public APIs unless requested.
5. Review the diff and run focused checks.
6. Report changed files, tests and any known limitation concisely.
