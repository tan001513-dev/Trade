# Plan Feature

Use this workflow only when the task is relevant.
1. Clarify the goal, constraints and acceptance criteria; avoid needless questions.
2. Inspect the smallest relevant files and existing conventions first.
3. Propose a short plan for nontrivial changes.
4. Perform the smallest correct implementation or analysis.
5. Validate with targeted tests or evidence; report what was not checked.
6. Summarize outcomes, affected files, remaining risks and next action concisely.

Specialty: Plan an application feature with requirements, edge cases, implementation steps and acceptance criteria.
For financial and personal data: use synthetic fixtures, tenant isolation, least privilege, audit trails, and human approval for consequential outputs. Never assert regulatory compliance without verification.
