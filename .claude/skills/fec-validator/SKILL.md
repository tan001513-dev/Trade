# fec-validator

Check delimiter, encoding, required fields, dates, numeric amounts, journal sequencing and consistency according to applicable specification. Distinguish structural validation from fiscal compliance. Never silently alter original data.

## Output
Give concise findings, exact changed files, tests run, and blockers. Do not read the whole repository unless justified.
